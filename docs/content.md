# Content Guide

## Voice

The product voice is calm, focused, and slightly nocturnal. It should feel like a quiet workspace, not a loud productivity app.

Use short, useful copy. Avoid motivational clutter.

## Product Name Placeholder

Use `Todo` as the working product name until a final brand name is chosen.
