# Note Studio reward-style preview

- Date: 2026-06-23
- Objective: Create a visual preview for redesigning the Notes page so it feels less empty and matches the Reward-style workspace direction.
- Created: `docs/previews/note-studio-reward-style-preview.svg`.
- Behavior changes: None. This is a static preview only and does not modify app code.
- Design direction:
  - Treat Notes as a Note Studio with a compact one-viewport layout.
  - Header includes filters, summary metrics, add action, and one note-themed sticker.
  - Main area uses collections on the left, featured/active note cards in the center, and quick capture plus recent notes on the right.
  - Empty space is replaced with purposeful quick capture, featured note, recent notes, and completed/archive affordances.
  - Existing note concepts remain: active, starred, dated, undated, completed, and quick-hub pinning.
- Shared design-system impact: None. No shared component or token was changed.
- Database/schema changes: None.
- Verification:
  - Preview file created and reviewed as a static SVG artifact.
